# LIV Restaurant — site vitrine (Abidjan)

Site statique (HTML, CSS, JavaScript), sans installation : ouvrez `index.html`.

## Infos utilisées (source : baab.ci, Instagram @livrestaurant.ci, fiche Google)
- 524 avenue N'guetta Timothée Ahoua (ex-7 décembre), Zone 4 — Marcory, Abidjan
- Téléphone : 07 59 70 07 00 (+225)
- Lundi fermé · Mar, Mer, Dim 19h30–minuit · Jeu 19h30–1h · Ven, Sam 19h30–2h30
- Bistronomie d'auteur, cadre très classe, ambiance festive · Climatisé, bar, paiement CB

Le badge « Ouvert / Fermé » et la ligne « aujourd'hui » des horaires se calculent automatiquement (heure d'Abidjan).

## Réservation
Le formulaire ouvre WhatsApp avec la demande pré-remplie vers le +225 07 59 70 07 00.
**À confirmer avec le restaurant que ce numéro est bien sur WhatsApp** (sinon changer `WHATSAPP` dans `js/main.js`).
Les lundis sont refusés automatiquement (jour de fermeture).

## Remplacer les photos
Photos d'illustration libres de droits (Unsplash). Remplacez les fichiers de `images/` en gardant les mêmes noms :
`hero.jpg` (accueil), `bust.jpg` (L'expérience), `dish-1..4.jpg` (La table), `bar.jpg` + `night-1..3.jpg` (LIV's Night),
`g1..g6.jpg` (Vos moments), `texture.jpg` (fond réservation).

Aucun nom de plat ni prix n'a été inventé : la section « La table » renvoie vers la story Instagram « Nos Cartes ».

`_ressources/` contient les captures d'origine et n'est pas publié.
